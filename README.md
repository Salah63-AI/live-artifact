# live-artifact

Working files for Tradex Trading & Contracting.

- `tradex-project-flow.html`: the project flow from cost estimate to customer and subcontractor progress billing, with owner, Odoo document and control for each step, plus a monthly progress log per project.

## Using it

Open `tradex-project-flow.html` in a browser and sign in. The first time, choose **Create an account**, confirm the email Supabase sends, then sign in. Only emails on the editors list can see or change the data.

Everything is stored in the Supabase project "live artifact" (eu-central-1). Each change is saved when you press Save and logged with who made it and when; open **History** on a step to see its past versions.
